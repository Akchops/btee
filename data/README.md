# data/ — the single source of truth

Everything in this directory is **authored fiction** for an explicitly fictional test
commission (AURELIS, Ko Lamphu). None of it describes a real place, person, business,
or measurement.

Rules that hold for this project and any future one:

1. Every factual or numeric value that appears anywhere in the rendered site
   originates here. No component contains a brand fact or a bare number.
2. Values are either AUTHORED (stated here) or DERIVED (computed in `src/lib/`
   from authored values). Derived values are never stored.
3. On a real client commission, anything presented as measurable fact must come
   from verified client material or explicit client approval. Invented facts must
   never be passed off as client truth.
